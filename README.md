# Multistep Subscription Form

A responsive multistep subscription form built with React and Next.js. The project focuses on a clear user experience, step-by-step form navigation, client-side validation, and reusable UI components.

## Features

- **Multistep navigation:** Divide the subscription process into manageable steps.
- **Form validation:** Validate user input and provide feedback before proceeding to the next step.
- **Subscription customization:** Select a subscription plan and optional add-ons.
- **Dynamic pricing:** Display the total cost based on the selected plan and add-ons.
- **Responsive design:** Adapt the interface to different screen sizes.

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd <repository-directory>
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Status

The frontend implementation is complete. The project currently focuses on the user interface, client-side form validation, subscription selection, and navigation between steps. Server-side submission and persistent data storage are not implemented.

## Purpose

This project was built to practise React and Next.js development, form state management, validation, component organization, and responsive UI implementation.
