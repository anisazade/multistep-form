A responsive multistep subscription form built with Next.js, React, and TypeScript. 
This project currently focuses on the frontend side only. Server-side submission and data storage are not implemented.

- **Live Demo:** [https://multistep-form-beta-ivory.vercel.app/](https://multistep-form-beta-ivory.vercel.app/)
- **Challenge Prompt:** [Frontend Mentor](https://www.frontendmentor.io/challenges/multistep-form-YVAnSdqQBJ)

## Features

- **Multistep Navigation:** Breaks the subscription flow into clear, manageable steps.
- **Client-Side Validation:** Custom validation for each input field with error feedback before moving to the next step.
- **Data Preservation:** Keeps form input values saved in local state so refreshing the page doesn't reset user progress.
- **Dynamic Pricing:** Calculates and displays total monthly or yearly costs based on the selected plan and add-ons.
- **Accessibility:** Designed with screen readers and keyboard navigation in mind, using semantic elements and accessible error announcements.
- **Responsive Layout:** Adjusts layout and navigation placement cleanly across mobile and desktop viewports.

## Technologies Used

- **Next.js** — React framework for application structure and routing.
- **React** — Component-driven architecture and step state management.
- **TypeScript** — Type safety across form state, plans, and validation schemas.
- **Vanilla CSS** — Custom styling for components, active states, and mobile adaptation.
